# dsh-window-fit

把 DeepSeek Harness 桌面窗口固定在屏幕的一块比例区域里，并在 **设置 → 通用** 里直接改大小。

DSH 桌面版的默认窗口是 1280×820，在高分屏上要么太小要么正好占满；这个插件在每次启动时把主窗口缩放到「屏幕宽 × 宽度比例 / 屏幕高 × 高度比例」并居中，比例随时可以在设置里改。

> 仅 Windows 有效（通过 Win32 `SetWindowPos` 调整窗口）。

## 安装

```bash
dsh plugin add dsh-window-fit
```

或在 **插件 → 添加插件** 里填包名 `dsh-window-fit`，也可以直接安装本地目录。

安装后在 **设置 → 通用** 会多出一行「窗口大小」：

- **宽 / 高**：窗口占屏幕的百分比（默认 78.75% × 81.44%，在 2560×1600 屏上是 2016×1303）；
- **保存并应用**：写入配置并**立即**调整窗口，以后每次启动都按这个比例；
- **立即应用**：只按输入框里的数值临时调一次，不写入配置（下次启动仍用已保存的比例）。

## 默认比例的含义

| 屏幕 | 默认窗口 |
|---|---|
| 2560×1600（150% 缩放） | 2016×1303 |
| 1920×1080 | 1512×880 |
| 3840×2160 | 3024×1759 |

想改就改百分比，比如都填 `70` 就是屏幕的 70%。

## 已知限制

- 只在 Windows 上工作；其他平台安装后不做任何事。
- DSH 自身有最小窗口尺寸，比例设得太小时会被程序抬高。
- 固定比例，不记忆你手动拖动后的尺寸；要换回默认行为，禁用或卸载插件即可。
- 需要系统允许运行脚本：插件通过 `wscript.exe` 以隐藏窗口启动 PowerShell 完成一次窗口调整，不修改任何系统策略。
- 调整时如果窗口处于最小化状态，会被短暂还原再最小化；正常启动时窗口是可见的，看不到这一步。

## 排查

窗口没有按比例变化时，看 `%TEMP%\dsh-window-fit.log`：里面记录了插件激活、目标尺寸和实际结果。
