# 窗口尺寸

每次 DeepSeek Harness 桌面版启动时，把主窗口调整成屏幕的一个固定比例并居中，代替程序内置的 1280×820 默认尺寸。比例可以在 **设置 → 通用 → 窗口大小** 里直接修改。

## 行为

- 宿主启动时运行一次：以隐藏窗口方式调用 PowerShell 辅助脚本，最多等待 60 秒让主窗口出现。
- 目标尺寸按**物理像素**计算：宽度 = 屏幕宽 × 宽度比例，高度 = 屏幕高 × 高度比例，然后居中放置。
- 只调整位置与尺寸，不激活、不置顶，不改变最大化状态。
- 之后手动拖动窗口不会被改回去；下次启动时再次套用。
- 仅 Windows 有效。

## 设置行

设置 → 通用 里新增「窗口大小」：

| 控件 | 作用 |
|---|---|
| 宽 / 高（%） | 窗口占屏幕的百分比，默认 78.75 × 81.44 |
| 保存并应用 | 写入插件配置并立即按新比例调整窗口；插件重启后继续使用该比例 |
| 立即应用 | 不写配置，只按输入框里的数值临时调整一次（下次启动仍用已保存的比例） |

设置行读写 `/api/window-fit/*` 路由，配置保存在当前 profile 的插件行里。

## 配置

| 字段 | 默认 | 含义 |
|---|---|---|
| `widthRatio` | `0.7875` | 窗口宽度占屏幕宽度的比例（0.1–1） |
| `heightRatio` | `0.8144` | 窗口高度占屏幕高度的比例（0.1–1） |
| `timeoutSeconds` | `60` | 等待主窗口出现的秒数（5–300） |

2560×1600 屏幕上默认对应 2016×1303，居中放在 (272, 148)。

## 排查

每次运行都会往 `%TEMP%\dsh-window-fit.log` 追加日志：插件激活、路由注册、辅助脚本目标尺寸与实际结果。窗口没有变化时先看这个文件。

## 已知限制

- 程序自身有最小窗口尺寸，比例过小时会被它抬高。
- 需要系统允许运行 PowerShell 脚本；插件通过 `wscript.exe` 隐藏启动，使用 `-ExecutionPolicy Bypass`，不改动系统策略。
- 固定比例，不记忆手动拖动后的尺寸。
- 窗口最小化时调整会短暂还原再最小化；正常启动不可见。
